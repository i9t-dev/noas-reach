Noas-reach

Noas-reach is a full-text CiviCRM search extension.

Noas-reach aims to augment the standard search features of CiviCRM, on top of the FormBuilder and SearchKit extensions.

It adds an entity search form with a single "content" field. This new form allows to search for entities matching the given content.

By using FormBuilder and SearchKit, NoasReach exposes a form that you can configure like any other standard CiviCRM form: Add fields, change appearance, change the search logic, reuse the form anywhere in the CiviCRM interface...

Features (✅: implemented, 🚧: work in progress, 🔮: planned):
  • ✅ Search through all CiviCRM entities: contacts, donations, memberships, events, etc.
  • ✅ Show entities corresponding to a search query
  • ✅ Find entities via a dynamic search form
  • ✅ Present search results as a table
  • ✅ Allow the user to modify the search form using the CiviCRM interface
  • ✅ Allow the user to manipulate the entity search form as any FormBuilder form: Add columns, change its style, integrate it into custom reports...
  • ✅ Search through all text fields of managed entities: name, address, email, phone, etc.
  • ✅ Index entities at installation time
  • 🚧 Update the indexed entities automatically when they change: creation, update, deletion
  • 🔮 For each entity in the search results, show a link to the entity
  • 🔮 When clicking the link to an entity, open a CiviCRM page to view the entity
  • 🔮 Run an advanced full-text search query
  • 🔮 Perform advanced view operations: filtering, ordering, grouping

Install

  • Download the extension package from the release page
  • Copy the noas-reach-X.Y.Z+VERSION-NAME.tar.gz file to the ext directory of your CiviCRM instance
  • In the CiviCRM interface, open the Administer / System Settings / Extensions page from the top-bar menu
  • Click the "add new" button to show the list of installable extensions
  • Search "noa" to find this extension in the list
  • Click the "install" button and complete the installation process

Use

Installing the extension adds a new item in the search menu of the top bar, named "find contents". Click this menu item to open the new content-search form.

The search form contains a single content field. Input a text search query to specify the text content you seek.

A table shows all the entities that contain a text field that matches your query. By default, the table shows all the entities in the database.
