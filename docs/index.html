Noas-reach

Noas-reach is a full-text CiviCRM search extension.
Features (✅: implemented, 🚧: work in progress, 🔮: planned):
  • ✅ Search CiviCRM contacts
  • ✅ Show entities corresponding to a search query
  • 🚧 Handle a subset of the search syntax of Apache Lucene, including:
    • Full-text search: Bob Smith searches for "Bob Smith" through all CiviCRM text fields
    • Unquoted terms: first_name:Bob
    • Quoted phrases: display_name:"Bob Smith"
    • Regular expressions: email:/.*smith@gmail\.com$/
    • Implicit logical operators: first_name:Bob first_name:Alice last_name:Smith
      ⇒ First name is either Bob or Alice and last name is Smith
    • Exclusions: -first_name:Bob
    • Match-all clause: *:* shows all entities
  • 🚧 Find entities via a dynamic search form
  • 🚧 Present search results as a table
  • 🔮 Search through all CRM entities: contacts, donations, memberships, events, etc.
  • 🔮 Perform advanced view operations: filtering, ordering, grouping
